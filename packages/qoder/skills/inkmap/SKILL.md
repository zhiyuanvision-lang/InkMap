# 在 Qoder 中打开 Inkmap

1. 确认用户指定了一份当前本地工作区中的 Markdown 文件。可使用任务中的文件引用或明确的路径。如果没有指定文件，或多个文件都匹配，先请用户选一份。
2. 使用本技能所在目录中的 `editor/inkmap.mjs`，从当前工作区根目录启动。给用户一条可直接粘贴到 Qoder 本地终端的命令。把脚本路径和 Markdown 路径替换为实际值，并按用户当前 shell 的规则引用每个参数，特别是空格、引号和其他特殊字符。脚本绝对路径来自已加载技能的文件位置，若无法确定该位置，请用户从解压的插件包中定位脚本。

   ```text
   node "<技能目录>/editor/inkmap.mjs" "<工作区中的 Markdown 路径>"
   ```

3. 说明需要 Node.js 22 或更新版本。终端出现 Inkmap 的本机地址后，让用户复制地址，在任务右侧点击「添加标签页 → 打开内置浏览器」并粘贴。编辑会写回所选 Markdown 文件。结束时可在终端按 Ctrl+C 关闭编辑会话。

为用户准备启动命令时，只需要文件路径，无需读取文档正文。请用户在本机终端和浏览器之间复制地址，地址包含当前编辑会话的访问凭证。远程任务请切换到文件所在设备的本地工作区。
