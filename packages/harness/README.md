# Markdown AI Mind Map — Inkmap (for DeepSeek Harness)

**Drowning in long, messy AI-generated Markdown specs and plans?**  
**Inkmap** turns complex local Markdown (`.md` / `.markmap.md`) into a **clear, two-way editable mind map** (Markmap alternative) and **visual Mermaid flowchart editor** directly inside the **DeepSeek Harness right sidebar**, with clipboard screenshot paste straight to `<doc>.assets/`.

![Inkmap Two-Way Sync Demo](https://www.zhiyuanv.com/assets/inkmap/demo-sync-en.gif)

## Quick Start

1. **Open in Right Sidebar**: Preview any `.md` file in DeepSeek Harness and click **Inkmap Mind Map** in the top-right preview toolbar.
2. **Paste & Drop Screenshots (`<doc>.assets/`)**: Press `⌘V` / `Ctrl+V` on a selected node (or drag `PNG` / `JPG` / `GIF` / `WebP` files onto a node) to save images into `<document>.assets/` and link them cleanly in Markdown.
3. **Full-Screen 3-Column Browser IDE**: Click **Open in Browser** in the Inkmap toolbar for a full-screen Project Tree + Markdown + Mind Map workspace.
4. **Live Browser Playground**: https://www.zhiyuanv.com/inkmap.html?lang=en
