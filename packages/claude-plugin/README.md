# Inkmap — Markdown Mind Map & Visual Mermaid Flowchart Plugin for Claude

**Inkmap** equips **Claude Code** and **Claude Desktop** with byte-preserving Markdown mind map (`.md`, `.markmap.md`), XMind-style outliner, and inline Mermaid diagram workflows — pairing seamlessly with the interactive Inkmap visual mind map & flowchart editor.

## Key Capabilities

- **Byte-Preserving Mind Map & Outline Authoring**: Structures complex technical architectures, brainstorms, PRDs, and study notes into clean CommonMark hierarchies that render interactively across 9 layouts (Mind Map, Logic Chart, Org Chart, Catalog, Timelines, and Fishbone).
- **Visual Inline Mermaid Flowcharts & KaTeX Math**: Embeds Mermaid flowcharts, sequence diagrams, state machines, Markdown tables, and KaTeX formulas directly inside mind map nodes — with direct click-to-edit flowchart nodes, connections, and shapes in the Inkmap diagram viewer.
- **Full Local Ecosystem & Clipboard Screenshot Paste**: Works seamlessly alongside the Inkmap MCP App (`npx -y inkmap-mcp@latest install`), VS Code / Cursor / Windsurf extensions, and the standalone Desktop App (macOS / Windows / Linux), where pressing `⌘V` / `Ctrl+V` or dropping images onto nodes automatically saves files to `<document>.assets/` with clean relative Markdown links.

Learn more at [zhiyuanv.com/software.html](https://zhiyuanv.com/software.html) and [github.com/zhiyuanvision-lang/InkMap](https://github.com/zhiyuanvision-lang/InkMap).
