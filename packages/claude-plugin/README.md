# Inkmap — Markdown Mind Map & Mermaid Flowchart Plugin for Claude

**Inkmap** equips Claude Code and Cowork with structured Markdown mind map (`.md`, `.markmap.md`), XMind-style outliner, and embedded Mermaid diagram authoring workflows, and pairs seamlessly with the interactive Inkmap visual mind map editor.

## Highlights

- **Clean Mind Map & Outline Authoring**: Structures complex technical architectures, brainstorms, PRDs, and study notes into clean CommonMark hierarchies that render cleanly as interactive Markmap mind maps, logic charts, org charts, timelines, and fishbone diagrams.
- **Inline Mermaid & KaTeX Support**: Embeds zoomable Mermaid flowcharts, sequence diagrams, state machines, Markdown tables, and KaTeX math formulas directly inside mind map branches.
- **Interactive Two-Way Visual Editor**: Works seamlessly alongside the Inkmap MCP App & IDE extensions (see https://zhiyuanv.com/software.html and https://github.com/zhiyuanvision-lang/InkMap for setup documentation).
